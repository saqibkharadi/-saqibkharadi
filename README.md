### 📖 My Story

I didn't start out knowing I wanted to work with code. Like a lot of people, I stumbled into it — curious about how things worked behind the screen, and one day I decided to stop wondering and just start learning. My first lines of code were messy, full of errors, and honestly a little intimidating. But something about solving a problem and watching it actually *work* pulled me in and never really let go.

Since then, my path has bent more and more toward **Artificial Intelligence and Machine Learning**. I'm fascinated by the idea that a machine can learn patterns from data the same way we learn from experience — and that fascination is what gets me up early to read papers, run experiments, and debug models that refuse to converge at 2 AM.

I'm still early in this journey. I don't have it all figured out, and I'm okay with that — every dataset I clean, every model I train, and every mistake I make is teaching me something a tutorial alone never could. My goal isn't just to learn AI/ML as a skill, but to actually understand it deeply enough to build things that matter — tools that help people, not just impressive demos.

This GitHub profile is where I'm documenting that climb. It's not a finished portfolio — it's a work in progress, just like me.

> *"The expert in anything was once a beginner."*
